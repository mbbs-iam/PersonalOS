# PersonalOS

I designed my PersonalOS thanks to a course offered by The NASA Stardance Challenge, where you learn to develop while having the opportunity to win rewards. With their tutorial, I managed to design my customized OS; using the 2026 World Cup stadium in America, I used my favorite player, Lamine Yamal, to lead this style.

I learned so many things that I don't know where to start. This is the first time I'm coding in HTML, CSS, and JavaScript, and I find it simple. And these languages are pretty much things you have to learn by heart, which perfectly suits the only skill I have: a good memory.
